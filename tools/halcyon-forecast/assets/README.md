# weather-icons.ttf

Ten icons from [Material Symbols Rounded](https://github.com/google/material-design-icons) by Google, under the
Apache License 2.0 (`/licenses/Apache-2.0.txt` in this repository, or https://www.apache.org/licenses/LICENSE-2.0).

Changed from the original: the Regular instance (wght 400, FILL 0, GRAD 0, opsz 24) cut to the glyphs the window uses
(clear_day, bedtime, partly_cloudy_day, partly_cloudy_night, foggy, rainy, weather_snowy, thunderstorm, cloud,
near_me) with fontTools' subsetter, and renamed "Halcyon Weather Icons" so it never stands in for the full font.
