# Settings reference

Every key in `~/.config/halcyon/settings.json`, with its type and
default. Only your overrides are stored — anything you have not
changed takes the value below.

```sh
halcyon settings get glass.opacity
halcyon settings set glass.opacity 0.55
halcyon settings unset glass.opacity   # back to the default
halcyon settings list                  # only what you have changed
halcyon settings path                  # where the file lives
```

Values are type-checked on the way in. An out-of-range number or an
unknown key is refused with the reason rather than quietly coerced,
and a change only reaches the desktop once `halcyon theme apply`
has regenerated the files — which the Settings app does for you.

## Appearance

Light and dark, the accent colour, fonts and cursors.

| Key | Type | Default | Meaning |
|---|---|---|---|
| `appearance.mode` | string | `"dark"` | `dark`, `light`, or `auto` to follow the time of day. |
| `appearance.followSunset` | bool | `false` | With `mode: auto`, switch at local sunrise and sunset rather than fixed hours. |
| `appearance.accentSource` | string | `"wallpaper"` | `wallpaper` derives the accent from the current image; `fixed` uses `accentColor`. |
| `appearance.accentColor` | string | `"#0A84FF"` | The accent when `accentSource` is `fixed`. Used exactly as given — a hand-picked colour is never clamped. |
| `appearance.iconTheme` | string | `"Papirus-Dark"` | Icon theme name, as installed under `share/icons`. |
| `appearance.cursorTheme` | string | `"Bibata-Modern-Classic"` | Cursor theme name. Applied to Hyprland, GTK and Qt together. |
| `appearance.cursorSize` | int | `24` | Cursor size in logical pixels. |
| `appearance.fontUi` | string | `"Inter"` | Interface typeface. Inter by default — an open font with the proportions this design wants. |
| `appearance.fontMono` | string | `"JetBrains Mono"` | Monospace typeface for the terminal module and code surfaces. |
| `appearance.fontSizeScale` | float | `1.0` | Multiplies every type size at once. `accessibility.textScale` is applied on top. |
| `appearance.cornerStyle` | string | `"continuous"` | `continuous` for squircle-style corners, `circular` for plain radii. |

## Glass

The material every surface is made of.

| Key | Type | Default | Meaning |
|---|---|---|---|
| `glass.preset` | string | `"tinted"` | Which shipped preset the other glass values started from. Changing a value by hand does not clear it. |
| `glass.opacity` | float | `0.6` | Base surface opacity, before per-elevation adjustment. Lower means more wallpaper. |
| `glass.blurStrength` | float | `1.0` | Scales the blur radius and pass count. The single biggest GPU cost in the desktop. |
| `glass.saturation` | float | `1.2` | Saturation boost applied to what shows through. Above 1.0 makes glass feel alive rather than grey. |
| `glass.tintStrength` | float | `0.22` | How much of the accent hue the glass carries. |
| `glass.borderOpacity` | float | `0.34` | Opacity of the hairline border that separates a surface from what is behind it. |
| `glass.cornerRadius` | int | `18` | Corner radius in logical pixels, shared by windows and shell surfaces. |
| `glass.shadowStrength` | float | `0.55` | Drop-shadow intensity. Feeds both Hyprland's shadow and the shell's. |
| `glass.panelPadding` | int | `12` | Interior padding inside panels. |
| `glass.widgetSpacing` | int | `10` | Gap between widgets within a panel. |
| `glass.specularStrength` | float | `0.5` | The highlight along a surface's top edge — what makes it read as glass rather than frosted plastic. |
| `glass.refraction` | float | `0.4` | How much the edge of a surface bends what is behind it. |
| `glass.noise` | float | `0.012` | A trace of grain over the material, which hides blur banding on large flat areas. |
| `glass.elevationSpread` | float | `1.0` | How far apart the elevation levels sit. Higher means a more pronounced depth hierarchy. |
