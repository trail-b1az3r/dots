# Halcyon 2.0.3 "(Re)polished Copper"

Copper polished back up after its weathering: a desktop that lasts longer on a battery and loses less.

- **Super battery saver.** One switch (the quick panel, Settings > Halcyon > On the screen, or `halcyon saver`): the
  screen is drawn at most 12 times a second (with hyprland-plus 0.57.0.p1's new `plus:max_fps`), brightness goes to
  20%, the power-saver profile is set, animations, blur and shadows go off, and Wi-Fi stops reconnecting by itself;
  it reconnects after boot, waking, locking and unlocking, and whenever you pick a network. Off puts back exactly what
  it found.
- **Alacritty is the terminal**, and Ctrl+C works on a Surface. kitty was set to copy instead of interrupt whenever
  any text was selected, which taps on a touchscreen or touchpad leave behind; in Alacritty Ctrl+C always interrupts
  and Ctrl+Shift+C copies. Its colours follow the theme, kitty's pins move to it once, and kitty's own config no
  longer does it either.
- **halcyon.UwU-agent** (universal web user [auth]) replaces plasma-nm: NetworkManager asks it for Wi-Fi passwords,
  which it answers from an encrypted vault or asks you for, and it keeps web logins too. Super + Alt + P picks one
  and copies the password for 45 seconds. `halcyon uwu` in a terminal.
- **Scratchpad and lost windows.** Super + Z drops a terminal down from the top of the screen and back (the same one
  each time); Super + S is still the scratchpad workspace. Super + Shift + W brings back windows that ended up off
  every screen; `halcyon lost` lists them.
- **The manga book opens smoothly.** It is built once and kept, so Super only plays the opening; a turning page now
  carries the real pages on both sides, so the left page no longer flashes when it lands.
- **Nexora Linux** gets its own logo in the bar and the quick panel.
- **hyprland-plus 0.57.0.p1**: every addition carried onto Hyprland 0.57.0, plus `plus:max_fps`.
