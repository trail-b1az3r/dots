# Halcyon 26.11.0.1.3 — (Re)polished Copper

This release focuses on making Halcyon updates reproducible and polishing the desktop experience.

## Fixes

- Build stable release archives through the repository's canonical `.build.sh` script so the archive layout matches the updater's expected source build.
- Replace the unavailable KDE Network Management KCM dependency with NetworkManager's native connection editor and `nmtui` fallback.
- Show Wi-Fi connection details inside Halcyon's own dialog using NetworkManager device information.
- Fix Alacritty's generated TOML theme: all terminal palette entries (`term0` through `term15`) and Material color tokens are substituted literally and validated before writing.
- Give HyperNeo its dedicated ember-and-neon wallpaper, resolved from the installed Pictures/Wallpapers directory.
- Repair theme-specific Alacritty and generic application icon glyphs across every built-in Halcyon theme.
- Add navigation and preview shortcuts to Nexora Write.

## Build and update

The release archive is generated by `bash ./.build.sh 26.11.0.1.3 dist`. CI validates the source tree before the stable workflow publishes the archive and checksum.
