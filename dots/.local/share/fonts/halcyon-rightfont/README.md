# RightFont

"The most confusing font possible", from Right of the Bell's video *I Made the Most Confusing Font Possible*
(https://youtu.be/NTY_yunv2To). Every letter still looks most like itself, but only just: it was graded against every
character in 1,600 fonts so that each one wins by a hair. You can probably read it. You can also misread it.

- Family: **RightFont Review** (RightFont Human v7, version 0.007), from https://www.rightofthebell.com/fonts
- Made from Inter and Open Sans, and like them under the SIL Open Font License 1.1 (OFL.txt here).

Installed by Halcyon to ~/.local/share/fonts/halcyon-rightfont. `halcyon fonts install right-font` puts it back, and
`halcyon fonts install right-font --latest` fetches the newest version from the site. Font Manager
(`halcyon fonts manager`) previews it.
